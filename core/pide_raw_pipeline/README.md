# Анализ сырых фотонных данных PIDE

Конвейер для шага 3: проверка модели порогового пересечения на сырых точках «доза–выживаемость» PIDE.

## Что нужно
- Файлы PIDE после регистрации в GSI: `PIDEx.x_PhotonRawData.dat` и `Pide_x.x.xls`.
- Python 3 с numpy, pandas, scipy; `discrete.py` лежит рядом.

## Запуск
Порядок колонок в `.dat` описан в `Information_sheet.pdf` из комплекта PIDE. Сверьте его и передайте номера колонок или их имена:

```
python3 pide_raw_analysis.py PIDE3.4_PhotonRawData.dat --id-col 0 --dose-col 1 --sf-col 2 --out pide34
python3 pide_raw_analysis.py PIDE3.4_PhotonRawData.dat --id-col 0 --dose-col 1 --sf-col 2 --model-fit --out pide34_model   # долго: подгонка точной модели
```

## Что считается
1. **Знак β** при LQ-подгонке на всём диапазоне доз, с z-оценкой. В однородной модели −ln S выпукла, поэтому значимо отрицательное β — маркер неоднородности.
2. **Коэффициенты при малых дозах** (D ≤ 3 Гр, не меньше 4 точек) и отношение R = α²/(2β) с погрешностью. Только к ним применима граница β ≥ α²/(2M).
3. **Подгонка точной модели** (флаг `--model-fit`) для M = 1, 2, 4, 10 и сравнение с LQ по AIC.

## Проверка на синтетических данных (`make_synthetic.py`)
40 кривых с шумом 5%: 12 однородных с M = 1, 17 однородных с M = 4 и 10 смесей (одна кривая отсеяна фильтром).
- Отрицательное β найдено у всех 10 смесей и ни у одной однородной кривой.
- Флаг «M ≥ 2» (R − 2·se > 1) сработал у 5 из 17 кривых с M = 4 и у 1 из 12 с M = 1 (ложная тревога).

Вывод: проверка по малым дозам годится только как отбор кандидатов. Окончательное суждение о M — по подгонке точной модели к сырым точкам.

## Условия PIDE
Файлы PIDE распространять нельзя: GSI просит каждого пользователя регистрироваться самостоятельно. Публиковать можно результаты анализа со ссылками Friedrich et al. 2013, 2021.
