# Код к статье «Lethal-threshold crossing in a stochastic lesion–repair model»

Код, которым получены все результаты и рисунки статьи: точная модель порогового
пересечения (процесс рождения–гибели с управляющим уравнением), её диффузионный
предел, вычислительные эксперименты по идентифицируемости и анализ опубликованных
кривых выживаемости.

Автор: Константин Рязанов, отделение медицинской физики, Онкологический центр
Калининградской области, Калининград, Российская Федерация.
ORCID: 0009-0003-8809-8494

## Что здесь есть и чего здесь нет

Пакет содержит **только код** и **собственные вычисленные результаты** автора
(файлы `*_results.json`, `*_summary.json`, `table_*.csv`), а также синтетические
данные для проверки конвейера.

**Исходные данные не включены**, и это не упущение:

| Что исключено | Причина |
|---|---|
| `PIDE_database.xlsx` и производный `photon_fit_table.csv` | GSI просит пользователей не перераспространять базу PIDE. Регистрация бесплатная: см. `core/pide_raw_pipeline/GSI_registration_request.txt` |
| База Polgár и производные от неё файлы точек | сторонняя база данных; цитируется, но не перераспространяется |
| PDF-файлы и сканы исходных публикаций | авторское право издателей |

Числовые значения, **переписанные из опубликованных таблиц** или **оцифрованные
автором с опубликованных рисунков**, включены в виде кода со ссылкой на источник
у каждой записи: `core/raw_survival/curves.py` и `data/analysis/digitize/`. Это
собственные производные измерения автора, и каждая запись атрибутирована.

## Установка

```
sh set_paths.sh                 # один раз: настроить пути под этот каталог
pip install -r requirements.txt
```

Python 3.11, numpy, scipy, matplotlib, pandas. Код сохранён в том виде, в котором
он произвёл опубликованные результаты, поэтому пути в нём абсолютные;
`set_paths.sh` заменяет два префикса (`/home/claude/pmb` → `core`,
`/home/claude/rawdata` → `data`) и больше ничего не меняет.

Скрипт правит файлы на месте, поэтому в клоне репозитория после его запуска
`git status` покажет изменения. Это ожидаемо; вернуть исходное состояние можно
командой `git checkout .`. Скрипты проверок и сборки в `core/arxiv/` путей не
зашивают и в `set_paths.sh` не нуждаются: корень они определяют сами
(`core/paths.py`, аргумент `--root` или переменная `FPLQM_ROOT`).

## Структура

```

  ssa.py, gsim.py          стохастическое моделирование (Гиллеспи, вложенная цепь)
  convexity_study.py       численная проверка выпуклости −ln S
  doserate_disc.py         протяжённое облучение и эффект мощности дозы
  recovery.py, recovery2.py   восстановление параметров по кинетике повреждений
  eta_bias.py              биномиальный недосчёт и фон
  profile.py               профили правдоподобия
  figs_v2.py, fig5.py, fig6.py   рисунки 1–6
  pide_analysis/           обработка таблицы PIDE (данные получить самостоятельно)
  pide_raw_pipeline/       анализ сырых точек PIDE + синтетическая проверка
  raw_survival/            кривые из опубликованных таблиц и их подгонка
  arxiv/analysis/          figS1 и сводные таблицы расширенной версии
data/analysis/             анализ опубликованных кривых
  predictive*.py           сравнение с LQ, предсказание вне выборки (рисунок 7)
  identifiability.py, a549.py   профили правдоподобия (рисунок 8)
  isotonic_*.py            тест на неубывание −ln S/D, калибровка размера теста
  energy_*.py, mv_*.py     перенос параметров между пучками внутри лаборатории
  design_sim*.py           вычислительные эксперименты по дизайну измерений

```

## Воспроизведение

Результаты, не требующие сторонних данных, воспроизводятся сразу:

```
cd core
python3 convexity_study.py        # выпуклость −ln S на 2.9e3 наборах параметров
python3 doserate_disc.py          # зависимость от мощности дозы
python3 recovery.py               # восстановление параметров, рисунок 5
python3 figs_v2.py                # рисунки 1–4
```

Результаты, требующие сторонних данных, перечислены в таблице выше; после
получения данных из первоисточника путь к ним задаётся в соответствующем
скрипте. Вычисленные автором результаты для сверки лежат рядом в виде
`*_results.json` и `table_*.csv`.

## Проверки выводов и сборка расширенной версии (добавлено 22.10.2026)

`core/paths.py` определяет корни без абсолютных путей: `--root PATH`, переменная
`FPLQM_ROOT` или поиск вверх до каталога с `discrete.py`; для данных — `--data PATH`,
`FPLQM_DATA` или `../rawdata`, `./data`, `../data`.

Независимая проверка математики приложения A, LaTeX и файлы рукописи не нужны:

    cd core && python3 arxiv/checks/derivations_check.py

12 символьных тождеств, затем численно alpha и beta против конечных разностей `-ln S`,
частный случай `n_c=1` и показатель степенного хвоста стационарного распределения.
Код возврата 0 — пройдено, 1 — есть провалившиеся.

Скрипты сборки расширенной версии (`arxiv/build_en.py`, `arxiv/build_ru.py`,
`arxiv/make_ru_pdflatex.py`) и подготовки её материалов (`arxiv/analysis/`) включены для
полноты; им нужен каталог с исходниками рукописи, в этот депозит не входящий.
`arxiv/analysis/make_appE.py` сохранён как исторический генератор: цепочка
appE_en.tex -> supplementary.tex замкнулась, и повторный прогон невозможен, о чём скрипт
сообщает явно.
